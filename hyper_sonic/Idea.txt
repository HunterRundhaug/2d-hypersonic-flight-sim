



Core Goal 1

Implement a deterministic 2D flight simulation in C++ that updates a 
vehicle’s state over a fixed number of timesteps using configurable 
vehicle and environment parameters, then exports the full simulation 
history to a CSV file for analysis.

Basic physics calculation ever update step:

	Thrust force = Thrust * direction // TODO make sure direction is normalized
	Gravity force = (0, -mass * gravity)

	drag force = 1/2 * mass * speed^2 * drag_coefficient * A(i.e reference area)

	Total force = (Thrust force) + Gravity force + drag force

	acceleration = (Total force) / mass
	new Velocity = old velocity + (acceleration * deltaTime)

	finally update position:
	new position = old pos + new Velocity * deltaTime
